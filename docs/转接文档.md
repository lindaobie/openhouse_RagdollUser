## 五、工具清单与用法

| 工具 | 用法 | 说明 |
|---|---|---|
| `Check-Driver.bat` | 双击 | 只读。判断 SteamVR 里装的是 openhouse 还是原厂；被覆盖时报红 |
| `Check-Flashes.bat` | 关闭 SteamVR 后双击 | 抓 20 秒闪光布局到 `tools\flashes.txt`。**判断轮班是否成立的关键证据** |
| `coverage.py` | `python tools\coverage.py 900 out.csv` | 连驱动遥测口 `127.0.0.1:36840`（换行分隔 JSON），统计每台基站对每个设备的贡献帧数 |
| `build-firmware.cmd` | 双击或 `build-firmware.cmd clean` | 编译固件到 `repo\openhouse\basestation_firmware\build\firmware.bin` |
| `tel.py`（临时脚本） | `python tools\_scratch\tel.py` | 一次性打印基站 / 房间 / 覆盖的当前状态，**排查时最常用** |

### 闪光布局怎么读

```
LHR-xxx: 120 groups/s, flashes/group 3:100%
  @  0us  seen 100%  sweeps after 33% (1/3.0)  180 hits/s
  @251us  seen 100%  sweeps after 33% (1/3.0)  213 hits/s
  @498us  seen 100%  sweeps after 33% (1/3.0)  294 hits/s
  => multi stagger, slots relative to first: 0 1 2
```

- `flashes/group 3:100%` = 每组三次闪光，三台都在
- `sweeps after` = 这一槽位的站有多大比例的闪光后面跟着扫描
- **三台正常时各为 `1/3.0`**；若主站为 `1/1.0` 而另两槽为 `-`，说明主站没数到从站（见第七节）
- 偏移必须是 0 / 250 / 500 µs 左右

## 七、未解决的问题（★ 下次优先处理）

### 7.1 某台基站在主站模式下收不到从站闪光

**现象**：`LHB-1DA59AC0` 当主站（频道 1）时，闪光布局长期为
`@0us 100% (1/1.0)`、另两槽为 `-`，即它从不统计其他基站。把它改成从站、
换另一台当主站后，三台立刻恢复 `1/3.0` 等分轮班。

**关键点**：这台机器当从站时完全正常（能锁相位、能扫描）——所以不是接收器坏了，
而是**主站模式下收听从站闪光**这条路径有问题。

**已排除**：距离（3–4 米）、角度（对准后无变化）、固件时序（三台闪光严格在 250 µs 网格上）。

**下次可以考虑**：
- 查 `basestation_firmware/src/timebase.c` 的 `optical_edge()` / `flash_slot()`：
  主站（`MC->slot == 0`）路径与从站路径的差异，特别是 `last_edge` 的更新时机
- 该机接串口读 `multi` 控制台命令，看 `seen_ms[]` 的年龄（**注意：这台机器的 USB CDC
  在 Windows 上会报错误码 10，驱动起不来**，需要先解决 USB 串口驱动）
- 若能编译驱动，加日志确认 `multi_seen()` 是否被调用

### 7.2 驱动侧多站解码器在未激活时丢弃日志

## 九、踩过的坑（不要重复）

### 9.1 环境类

| 坑 | 正确做法 |
|---|---|
| `git` 全局代理 `socks5://127.0.0.1:10808` 是死的 | 用 `git -c http.proxy= -c https.proxy= clone/fetch` 直连 |
| GitHub API 匿名限流 | release 资产改用 `curl -L` 直链；API 用 `Invoke-WebRequest` 带 `Accept: application/octet-stream` |
| 沙盒禁止 `powershell -File` | 需要执行 ps1 时让用户双击 .bat |
| 命令里出现 `-ExecutionPolicy Bypass` 会被沙盒拦截 | 改写 .bat 时不要把它放进 shell 命令，用 write 工具写文件 |
| `.bat` 必须是 **ASCII + CRLF** | 用 `[Text.ASCIIEncoding]` 写，`\n` 全部换成 `\r\n`；LF 换行会导致 cmd 解析失败、窗口闪退 |
| `.ps1` 必须 **UTF-8 带 BOM** | 否则 PowerShell 5.1 按 GBK 解析，中文全乱 |
| 控制台代码页 936 | .bat 里不要写 UTF-8 中文，中文放到 .ps1 里 |
| 系统盘是 `A:`，无 `C:` | 基站进 ISP 时会占用 `C:`，这时别让其他程序往 C: 写东西 |

### 9.2 硬件类

| 坑 | 说明 |
|---|---|
| 刷机 micro-USB 必须是数据线 | 充电线插上去盘不出现 |
| 插拔顺序固定 | 断电 → 按住背面按钮 → 插 USB → 插电源 → 松手 |
| 别用资源管理器拖 firmware.bin | 会写错偏移，作者实测前 3 KB 丢失 |
| Windows 弹"需要格式化"千万别点 | 那个卷是 ROM 合成的假 FAT |
| `backups\` 不可再生 | 里面是每台的原厂镜像与工厂标定 |

### 9.3 排查类

| 坑 | 说明 |
|---|---|
| 主站收不到从站时仍会自动广播 OOTX | 三台都会出现在 SteamVR 列表里，`seen=True`，但只有一台出帧。**看 coverage 不看 seen** |
| 闪光布局采集需要 tracker 醒着 | SteamVR 退出会把设备关机；采集前先按 tracker 电源键 |
| `lhcapture --check` 不会自己停 | 只会打印到 Ctrl-C；`tools\Check-Flashes.ps1` 会用 20 秒后 kill 掉 |
| SteamVR 已运行时 `vrstartup.exe` 不会再起一个 | 想换环境变量必须先彻底关掉 |
| `driver_lighthouse.dll.stock` 不能进公开仓库 | Valve 的版权文件；上游明确写了 "Never ship Valve's files" |
